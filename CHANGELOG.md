# Changelog

## 0.1.2

- Require named MCP API keys for HTTP `/mcp` requests.
- Add encrypted local Infinity credential profiles for Docker and cloud deployments.
- Add credential setup commands for profiles, users, listing, and key rotation.
- Enforce read, write, and admin scopes across MCP tools.
- Update Docker and setup documentation for multi-user secure mode.

## 0.1.1

- Add optional `MCP_AUTH_TOKEN` protection for HTTP MCP requests.
- Add public distribution metadata to `package.json`.
- Document security guidance for local and remote deployments.
- Document the project versioning rule.

## 0.1.0

- Initial public Infinity MCP server.
